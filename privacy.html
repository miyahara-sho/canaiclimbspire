Privacy Policy — CanAIClimbSpire Uploader

Last updated: September 27, 2026 (rev. 2)

CanAIClimbSpire Uploader (“the App”) is a private tool used only by the owner of the YouTube channel “AIは尖塔を登れるか｜スレスパ2” (UCK9gXZSAwHOXrIFxd0LHO0A). It is not offered to, and cannot be used by, anyone else.

Use of YouTube API Services

This App uses YouTube API Services. By using the App, the user (the channel owner) agrees to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to data processed through YouTube API Services.

What the App does

The App uploads gameplay commentary videos (Slay the Spire 2) to the owner's own YouTube channel, sets their titles, descriptions and thumbnails, and reads the channel's own YouTube Analytics reports (views, watch time, audience retention) to improve future videos.

Google user data the App accesses

  • YouTube Data API: the owner's own channel and videos (upload, update metadata, list own videos).
  • YouTube Analytics API: aggregate, anonymized reports for the owner's own channel only.

The App does not access any other user's account, and does not collect, store or process personal data of viewers or any third party.

Storage and sharing

OAuth tokens are stored only on the owner's computer with restricted file permissions. Aggregate analytics numbers may be kept in local notes for the owner's own content planning. No Google user data is sold, shared with, or transferred to any third party, and none is used for advertising.

Limited Use

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service. See also the Google Privacy Policy.

Data retention and deletion

The App stores only an OAuth token and aggregate reports for the owner's own channel, on the owner's own computer. It does not store any data about other users or viewers. Data retrieved from YouTube API Services is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies, unless it is the owner's own content.

To revoke the App's access and delete stored data: remove "CanAIClimbSpire Uploader" at Google Account → Security → Third-party apps with account access (security.google.com/settings/security/permissions). The locally stored token is then deleted from the owner's computer within 7 days. For any deletion request, contact us via the address below.
